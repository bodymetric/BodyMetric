# Implementation Plan: Home Refresh After Workout Completion

**Branch**: `022-home-refresh-post-workout` | **Date**: 2026-05-31 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/022-home-refresh-post-workout/spec.md`

## Summary

When a workout session is completed and the user taps "Done" on `WorkoutCompleteView`, two things must happen: (1) `CheckInView` must dismiss itself (returning the user to `TodayView`), and (2) `TodayViewModel.reload()` must call `GET /api/home?currentDayOfWeek=<WEEKDAY>` to refresh the home screen. Additionally, `HomeService` must be updated to include the `currentDayOfWeek` query parameter on every request so the server returns the correct day's data.

Three file edits, no new types, no protocol changes.

## Implementation Notes

### HomeService — URL with query parameter

Replace the current URL construction:
```swift
// Before
guard let url = URL(string: Self.baseURL) else { ... }
let request = URLRequest(url: url)
```

With `URLComponents`:
```swift
// After
var components = URLComponents(string: Self.baseURL)!
components.queryItems = [
    URLQueryItem(name: "currentDayOfWeek", value: Self.currentDayOfWeekString())
]
guard let url = components.url else { throw WorkoutPlanError.networkError(URLError(.badURL)) }
let request = URLRequest(url: url)
```

And the helper (private static):
```swift
private static func currentDayOfWeekString() -> String {
    let f = DateFormatter()
    f.dateFormat = "EEEE"
    f.locale = Locale(identifier: "en_US")
    return f.string(from: Date()).uppercased()
}
```

### CheckInView — dismiss on workout complete

```swift
// Before (line ~205)
onComplete: { path.removeLast() }

// After
onComplete: { dismiss() }
```

### TodayView — reload on CheckIn dismiss

```swift
// Add inside NavigationStack modifier chain
.onChange(of: showCheckIn) { old, new in
    guard old && !new else { return }
    Task { await viewModel.reload(using: homeService) }
}
```
